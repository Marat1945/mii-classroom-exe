# Пакет для створення Windows `.exe`

**Це ще не `.exe`.** У цьому ZIP — програма та інструкція для автоматичної
збірки готового `.exe` у GitHub Actions на Windows.

Розпочніть із документа **«ЯК ЗІБРАТИ EXE БЕЗ PYTHON.md»**.

На вашому комп'ютері **не потрібно** встановлювати Python або бібліотеки.
Сервіс GitHub Actions сам збирає виконуваний файл на Windows.

**Увага:** налаштування доступу Google OAuth та AI API виконуються окремо.
Програма не створює й не публікує матеріали в Classroom без вашого дозволу.
