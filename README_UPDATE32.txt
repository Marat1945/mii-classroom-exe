ПОМІЧНИК УЧИТЕЛЯ — ПАКЕТ 3.2
===========================

ЩО ДОДАНО
• «МІЙ CLASSROOM — ПЕРЕГЛЯД» — вибір класу, оновлення попередніх
  опублікованих матеріалів/завдань і чернеток. Опис, дата, статус,
  вкладення, доступні мініатюри; пошук і фільтри.
• Оголошення зі стрічки — окремий перемикач і разовий
  додатковий дозвіл Google ТІЛЬКИ на читання оголошень.
• Після синхронізації точний збіг дати і теми показує
  «Опубліковано в Classroom» у головній таблиці.
• Кнопка «СТВОРИТИ ЧЕРНЕТКИ ДЛЯ ВСІХ УРОКІВ ЦЬОГО ДНЯ».
  Перед створенням показує перелік і причини пропусків.
• Word НЕ обов'язковий. Чернетка можлива з текстом або лише
  зображенням/файлом. Порожній матеріал не створюється.
• Контекстне меню в повідомленні Classroom, копіювання матеріалу
  у декілька вибраних уроків, перетягування файлів на рядок.
• Стовпчик «Дата» в КТП; окреме (необов'язкове) коригування
  чисельника/знаменника з другого семестру.
• КТП після теми та перестановка колонок перетягуванням,
  вибір КТП/курсу в таблиці за одним натисканням.

ЯК ОНОВИТИ GITHUB
1. Збережіть попередній працюючий EXE.
2. Розпакуйте UPDATE32.zip.
3. Відкрийте github.com/Marat1945/mii-classroom-exe
4. Add file → Upload files.
5. Перетягніть тільки дві папки: classroom_assistant і tests.
   В архіві НЕМАЄ прихованої папки .github і НЕМАЄ JSON/API-ключів.
6. Commit changes. GitHub Actions автоматично спробує скласти EXE.
7. Завантажте готову збірку після зеленої галочки,
   розпакуйте й протестуйте поруч зі старою версією.

ВАЖЛИВО
• Опубліковані матеріали не редагуються й не видаляються.
• Кнопки створення чернеток створюють тільки DRAFT, не PUBLISHED.
• Перегляд Classroom працює через Google API, без OpenAI.
• Для попередніх файлів Google може дозволяти тільки назви,
  мініатюри й відкриття у Drive; це обмеження доступу, не помилка.
• Якщо оголошення вмикати вперше, Google може попросити
  ОКРЕМИЙ одноразовий дозвіл. Новий OAuth JSON не потрібен.
• Встановлені локальні КТП та OAuth-ключі НЕ додавайте у GitHub.
