# Код Марса для Windows

Версия шифровальной программы «Код Марса» для компьютера: альбомное окно,
те же ключи, автокод по дате, ключ-фраза, шифровка Base32, азбука Морзе и QR-код,
что и в Android-версии от 16.06.2025. Шифровки полностью совместимы: сообщение
с телефона расшифровывается на компьютере, сообщение с компьютера — на телефоне.

## Как получить KodMarsa.exe через GitHub

Нужны два файла: архив `kod-marsa-exe.zip` (его не распаковывать) и файл сборки `main.yml`.

1. В репозитории: вкладка **Code** → **Add file** → **Upload files**, перетащите `kod-marsa-exe.zip`, нажмите **Commit changes**.
2. Откройте файл `.github/workflows/main.yml`, нажмите карандаш (**Edit this file**), нажмите Ctrl+A, вставьте текст из `main.yml`, нажмите **Commit changes** → **Commit changes**. Если такого файла ещё нет: вкладка **Actions** → **set up a workflow yourself**.
3. Вкладка **Actions** → верхний запуск «Сборка KodMarsa.exe». Через 3–5 минут появится зелёная галочка. Откройте запуск и внизу, в разделе **Artifacts**, скачайте `KodMarsa-Windows`: внутри `KodMarsa.exe`.

Чтобы обновить программу, загрузите новый `kod-marsa-exe.zip`: сборка всегда берёт самый свежий архив.

При первом запуске Windows может показать окно «Windows защитил ваш компьютер»:
программа не подписана платным сертификатом. Нажмите «Подробнее», затем «Выполнить в любом случае».

## Что умеет программа

- Шифрование AES-256 ключом из списка или ключ-фразой; автокод по числу месяца, как на телефоне; автоподбор ключа другого дня.
- Четыре языка интерфейса: русский, украинский, польский, английский (кнопка слева от «Справки»).
- Стрелки «назад» и «вперёд» (Alt+← и Alt+→) возвращают операции этого сеанса.
- QR-код: сохранить, скопировать, перетащить мышью; прочитать из файла, буфера или с экрана.
- «Поделиться» в меню правой кнопки у шифровки, морзянки и QR: Telegram, Viber, Instagram, Delta Chat
  (список настраивается в меню ☰ слева от названия).
- Азбука Морзе звуком: текущий знак подсвечивается, переданные сигналы и буквы шифровки краснеют и подчёркиваются;
  передача начинается с места курсора. Настройка: скорость, Фарнсворт, тон, громкость, помехи, разделители,
  автоопределение языка, сохранение в WAV.
- SSTV: передача картинки QR-кода звуком — Martin 1/2, PD 50/90/120/160/180/240/290, Scottie 1/2/DX, Robot 36/72,
  Wraase SC2-180; ход передачи виден на QR-коде.
- Бланк «Шифровка» в PNG и Word: номер вида 041026/001, ключ, QR, группы по 5 знаков, несколько листов.
  В Word текст документа — только шифровка: «Выделить всё» и копирование берут её целиком, без пробелов.
- Всё созданное сохраняется в «Документы\\Код Марса». Операции программа помнит только до закрытия,
  язык и настройки — постоянно.

## Важно о ключах

- 32 ключа списка встроены в программу, как и в APK. У кого есть программа, у того есть и эти ключи.
  Для по-настоящему секретной переписки используйте ключ-фразу, известную только участникам.
- В документе «Шифры на каждый день месяца» колонка «шифр» не является SHA-256 от фразы
  в колонке «слова». Программа берёт HEX-ключи напрямую, поэтому список совместим с телефоном.
  Но если ввести фразу из этой таблицы в режиме «Ключ-фраза», получится другой ключ.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `kod_marsa.py` | окно программы |
| `marscore.py` | ключи, AES-256, Base32, QR |
| `marsmorse.py` | азбука Морзе и звук |
| `marssstv.py` | передача SSTV |
| `marsform.py` | бланк PNG и Word |
| `marsi18n.py` | четыре языка |
| `tests/test_compat.py` | проверка совместимости с Android-версией |
| `tests/android_vectors.tsv` | эталонные шифровки, сделанные кодом из APK |
| `assets/` | логотип, фон, иконка и бланк из Android-проекта |
| `.github/workflows/main.yml` | сборка EXE на GitHub |

Запуск без сборки (нужен Python 3.12):

```
pip install -r requirements.txt
python kod_marsa.py
```
