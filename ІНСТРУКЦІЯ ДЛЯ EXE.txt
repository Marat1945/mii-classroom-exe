ПОМІЧНИК УЧИТЕЛЯ — WINDOWS .EXE
================================

ПІСЛЯ ЗАВАНТАЖЕННЯ ГОТОВОГО EXE:
1. Розпакуйте ZIP, завантажений зі сторінки GitHub Actions.
2. Двічі натисніть Pomichnyk_Uchytelia.exe.
3. Python та бібліотеки на вашому Windows НЕ ПОТРІБНІ.
4. При першому запуску програма самостійно створить приватну папку
   %LOCALAPPDATA%\PomichnykUchyteliaClassroom\
   з вашим розкладом і календарними планами.
5. До авторизації Google програма нічого не додає в Classroom.
6. Повні лекції Word — безкоштовно через ваш ChatGPT (кнопка «Word: лекція через ChatGPT»).
   Платний автоматичний варіант через OpenAI API — необов'язковий.
7. Для Google Classroom потрібні OAuth JSON + ваше підтвердження дозволів.

ВАЖЛИВО:
- EXE не має цифрового підпису; Windows SmartScreen може попередити
  про невідомого розробника. Перевіряйте джерело файла.
- Цей EXE НЕ був запущений на вашому комп'ютері; протестуйте спочатку локальний розклад.
- Ця збірка створює лише чернетки Classroom після вашого підтвердження,
  автоматична публікація не ввімкнена.
- Кнопка «Word: заготовка» створює лише ПОЗНАЧЕНУ ЗАГОТОВКУ, не повну лекцію;
  повну лекцію без API-ключа дає режим «через ChatGPT».
