ПОМІЧНИК УЧИТЕЛЯ CLASSROOM — ОНОВЛЕННЯ 4.0
===========================================

1. ЗБЕРЕЖЕННЯ З ПОРОЖНІМИ КТП — ВИПРАВЛЕНО НАСПРАВДІ
- У минулій версії помилку «Порожній КТП …» я прибрав лише з першої перевірки (у вікні редактора), а друга
  перевірка всередині самого запису на диск (persist) її лишала, тому на екрані й з'являлося «Помилка
  збереження». Мій тест тоді підмінював запис, тому не помітив. Тепер фільтр є в обох місцях, а тести
  перевіряють справжній запис на диск у тимчасовій папці. Справжні помилки (напр. кінець року раніше початку)
  блокують збереження, як і раніше.

2. УСІ ФАЙЛИ — ОДНИМ ПЕРЕТЯГУВАННЯМ, БЕЗ ЗАПИТАНЬ
- Перетягніть у БУДЬ-ЯКЕ місце вікна «Керування навчальним роком» стільки файлів, скільки треба: усі КТП, розклад
  (навіть разом). Під час перетягування угорі видно жовту підказку.
- Для кожного файлу програма сама визначає:
  • КТП це чи розклад — за змістом таблиці (дні «Понеділок…» → розклад), а не за назвою;
  • для якого класу й предмета КТП — за назвою файлу, шапкою документа, словами «профіль / стандарт / 3 год /
    1,5 год» і класами в стовпці дат; призначає кожному класу й паралелям (спільний КТП).
- Жодних запитань «Так / Ні»: ні «Замінити поточний план?», ні «Призначити за змістом?». Якщо клас уже мав
  КТП, його замінено, а в підсумку про це написано. Усе скасовується кнопкою «↶ Назад».
- Підсумок (одне вікно): «Імпортовано: 16 з 17», для кожного файлу — куди потрапив і скільки уроків; окремо
  — що не вдалося: зображення розкладу (JPG прочитати не можна), непідтримані формати, файли, для яких не
  видно клас і предмет («киньте його на потрібний клас»).
- Один файл: без вікон; рядок-примітка внизу («✓ файл → 8-Б ІУ, 8-В ІУ (52 уроків)»). Якщо стовпці не розпізнані,
  відкривається таблиця для ручного вибору стовпців.
- Кнопка «Імпортувати файли…» теж приймає кілька файлів.
- Розклад: у порожній програмі нові класи створюються самі (без запитання), розклад завантажується без
  підтверджень, канікули з першого рядка записуються, якщо в програмі їх ще не було.
- Єдине питання, що лишилося, — лише для ОДНОГО файлу, кинутого на клас, коли в файлі вказані інші класи, а
  відповідного в програмі немає («Перевірте клас»): інакше не обійтись без ризику вкласти КТП не туди.

3. ПЕРЕВІРЕНО НА ВАШИХ ФАЙЛАХ
- Розклад + усі 15 КТП + картинка (17 файлів) одним махом у порожню програму: 2,9 с, жодного запитання,
  16 з 17 імпортовано (картинка відхилена з поясненням), 25 потоків, усі мають КТП, 9-Б і 9-Г ІУ окремі,
  8 ІУ / 9 ВІ / 11 ВІ — спільні для паралелей, канікули з заголовка, у календарі 1038 готових уроків.

4. ДРІБНЕ
- Drop приймає й нижня смуга кнопок («Зберегти», «Назад», «Вперед»): реєстрація drop тепер у кінці побудови вікна.
- Курс без предметів: тимчасовий потік, що не знадобився, прибирається.
- Кнопка «Імпортувати DOCX / DOC / CSV» перейменована на «Імпортувати файли…».

КОНТРОЛЬНИЙ СЦЕНАРІЙ НА WINDOWS
Редактор → у Провіднику виділіть усі КТП (і розклад) → перетягніть у будь-яке місце вікна редактора. Має з'явитися
жовта підказка, а після відпускання один підсумок «Імпортовано: …». Потім «ЗБЕРЕГТИ ВСІ ЗМІНИ» — без помилок,
навіть якщо для якогось класу КТП не знайшлось.

ВІДОМІ ОБМЕЖЕННЯ
- Файли Word 97-2003 (.doc) читаються через Microsoft Word на Windows (кожен відкривається окремо, може бути
  повільно). Надійніше мати .docx; усі ваші КТП у папці «КТП джерела» вже є як .docx.
- JPG/PNG розкладу програма прочитати не може (розпізнавання тексту з картинки не передбачено): потрібен Word
  або Excel. Картинку «Навантаження» програма сама генерує з розкладу, а не читає.
- Автоматичне призначення спирається на назву файлу, шапку й дати; якщо там немає ознак класу чи предмета, файл
  потрапляє у список «не вдалося визначити» (у пакетному режимі) або програма питає (один файл).
