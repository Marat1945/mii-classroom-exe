ПОМІЧНИК УЧИТЕЛЯ CLASSROOM — ОНОВЛЕННЯ 3.3
============================================

РОЗГОРНУТІ ВІКНА
- Головне вікно, редактор КТП, попередній перегляд імпорту, бібліотека Word,
  довідка, налаштування, «Мій Classroom», вікна вибору й редагування
  відкриваються розгорнутими на весь екран.
- Вкладка «Навчальний рік, канікули» має вертикальне прокручування.
- Системні запитання «Так/Ні» не розгортаються.

ВИДАЛЕННЯ І КОПІЮВАННЯ
- КТП: правою кнопкою або Delete можна видалити не використаний іншими
  класами план; для використовуваного спочатку призначте інший план класу.
- Уроки КТП: Ctrl/Shift кілька рядків, правою кнопкою або Delete, Ctrl+C.
- Імпорт Word-КТП: вибрані рядки можна виключити з майбутнього імпорту
  правою кнопкою / Delete, не змінюючи оригінального файлу Word.
- Розклад: Delete очищає призначення потоків у вибраному уроці, але НЕ дзвінки.
- Класи/курси і канікули: правою кнопкою / Delete з підтвердженням.
- Головна таблиця: Ctrl+C копіює рядки; Delete відв'язує ТІЛЬКИ
  ЛОКАЛЬНІ Word, вкладення й описи. Word на диску, КТП та Google не видаляє.
- Вікно «Мій Classroom» читає Google, видаляти реальні роботи учнів не може.

ПЕРЕТЯГУВАННЯ ФАЙЛІВ З ПРОВІДНИКА
- Word, фото, PDF та інший файл можна тягнути ЛІВОЮ кнопкою миші
  на конкретний рядок у ГОЛОВНІЙ таблиці. Він підсвічується жовтим.
- Word .docx після підтвердження стане перевіреним документом уроку,
  інші файли додаються як вкладення до цього уроку.
- Поле опису й зона вкладень також приймають файли перетягуванням.
- Редактор: на КТП/клас переносимо DOCX/DOC/CSV для імпорту
  до потрібного КТП, на розклад — DOCX/DOC/XLSX/CSV.
- Нічого не надсилається в Google без окремої вашої дії.
- Технічно виправлено повернення операції Drop='copy', а не 'break'.
  ЦЮ ФУНКЦІЮ ЩЕ ТРЕБА ПЕРЕВІРИТИ В WINDOWS EXE.

ДАТИ Й КЛАСИ З КТП
- Якщо в імпортованому Word є «8-Б 04.09.; 8-В 04.09.; 8-Г 03.09.»,
  всі три дати тепер зберігаються для конкретного класу.
- Після імпорту зверху КТП виберіть клас, і стовпчик «Дата»
  покаже його власні дати, а не безумовний розрахунок розкладу.
- За відсутності дати у файлі показується розрахункова дата.
- Якщо дати з Word не збігаються з розкладом, програма
  попередить, але не змінюватиме розклад без вчителя.

CLASSROOM
- При натисканні «МІЙ CLASSROOM» записи вибраного курсу
  завантажуються автоматично. Окремої кнопки «Оновити» немає.
- При виборі іншого курсу запис оновлюється автоматично.
- Після синхронізації відображається справжній статус:
  завдання/матеріал ОПУБЛІКОВАНО, заплановано або чернетка.
- До синхронізації — «Створено в Google (статус не перевірено)»,
  щоб не називати вже опубліковане завдання чернеткою.

ЯК ЗІБРАТИ Windows EXE
1. Збережіть попередню робочу версію 3.2.
2. Розпакуйте U33.zip.
3. У GitHub Marat1945/mii-classroom-exe натисніть
   Add file → Upload files.
4. Перетягніть ЛИШЕ папки «classroom_assistant» і «tests».
5. Натисніть Commit changes.
6. Перевірте успіх збірки GitHub Actions, завантажте новий EXE.

Секрети і OAuth JSON до GitHub НЕ надсилати.
Усі дії з Google лишаються під контролем учителя.
