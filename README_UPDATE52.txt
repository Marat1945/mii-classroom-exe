ПОМІЧНИК УЧИТЕЛЯ CLASSROOM — ОНОВЛЕННЯ 5.2
===========================================

ЩО ЗРОБЛЕНО
Ваш логотип («Помічник учителя»: мідна рамка, заклепки, шапочка, список із галочками, зелена лампочка) тепер ІКОНКА програми:
   • у Провіднику: на файлі Pomichnyk_Uchytelia.exe (і на ярликах, створених із нього);
   • у заголовку вікна, на панелі завдань і в Alt+Tab (замість червоної пір'їнки Tk: це стандартна іконка, власної в програми
     досі не було);
   • прозорі кути: іконка гарно лягає і на світле, і на темне тло.

ЯК ЦЕ ВЛАШТОВАНО
   • app_icon.ico (у корені репозиторію) — іконка з усіма розмірами, які просить Windows: 16, 24, 32, 48, 64, 128 і 256 пікселів.
     Малі розміри (до 64) записано класичним BMP із прозорістю, великі (128, 256) — PNG: так іконку коректно показують усі
     версії Windows. Дрібні розміри трохи підгострено; напис «Помічник учителя» читається від 48 пікселів, а на 16 і 24 видно
     лише форму (шапочку й зелену лампочку): це неминуче для такого малого розміру.
   • Файл .exe отримує іконку під час збірки: у команду збірки на GitHub додано --icon "app_icon.ico"
     (.github/workflows/Windows_EXE.yml). Тому ПІСЛЯ завантаження файлів треба дочекатись нової збірки й завантажити НОВИЙ .exe.
   • Іконка вікна вбудована в сам код (файл поруч із .exe не потрібен). Також програма повідомляє Windows свою «мітку», щоб на
     панелі завдань стояла іконка програми.

КУДИ ЗАВАНТАЖУВАТИ (2 кроки, як завжди, але з однією новою папкою)
1. Розпакуйте U52.zip. Старий робочий EXE НЕ видаляйте.
2. github.com/Marat1945/mii-classroom-exe → Add file → Upload files → перетягніть УСЕ з розпакованої папки: тепер це 3 папки
   (classroom_assistant, tests, .github) і 5 файлів (в тому числі app_icon.ico) → Commit changes → Actions → зелена галочка →
   Artifact Pomichnyk_Uchytelia_Windows_EXE → Pomichnyk_Uchytelia.exe.
   ВАЖЛИВО: папка .github має назву з крапкою на початку. Якщо Провідник її не показує або GitHub її не прийняв, зробіть ТАК:
   завантажте решту, а потім на GitHub відкрийте файл .github/workflows/Windows_EXE.yml → олівець («Edit») → у рядку, що
   починається з «python -m PyInstaller», після «--windowed» додайте:   --icon "app_icon.ico"   → Commit changes.
   Без цієї зміни файл .exe збереться, але зі старою стандартною іконкою (вікно, втім, матиме логотип).

ЯКЩО ПІСЛЯ НОВОЇ ЗБІРКИ ІКОНКА В ПРОВІДНИКУ СТАРА
Windows запам'ятовує іконки й інколи тримається за стару. Допоможе будь-що з цього: скопіювати .exe в іншу папку чи
перейменувати; перезапустити Провідник (Диспетчер завдань → «Провідник Windows» → Перезапустити); перемкнути вигляд на
«Великі значки». Це не помилка програми.

       панелі завдань, і як поводиться кеш іконок.

КОНТРОЛЬНИЙ СЦЕНАРІЙ НА WINDOWS
1) Після зеленої галочки в Actions завантажте НОВИЙ Pomichnyk_Uchytelia.exe. 2) У Провіднику (вигляд «Великі значки») на файлі має
бути ваш логотип. 3) Запустіть: логотип у заголовку вікна й на панелі завдань. 4) Alt+Tab: теж логотип.

     а вікно її матиме.
