# Як одержати справжній Windows EXE без Python

Цей архів містить вихідний код вашого Помічника учителя, 15 календарних планів,
правила розкладу та файл автоматичної збірки `.github/workflows/Windows_EXE.yml`.

**Важливо:** у ZIP наразі **немає готового EXE**. Його потрібно один раз
зібрати в хмарному Windows-середовищі GitHub Actions. На вашому комп'ютері
не потрібно встановлювати Python і його бібліотеки.

## Покроково, без написання команд

1. Зареєструйтеся або ввійдіть на https://github.com/.
2. Натисніть **+ → New repository**. Назвіть `mii-classroom-exe`.
   **Виберіть Private**, оскільки ваші навчальні плани не мають бути публічними.
   Створіть репозиторій без автоматичного README.
3. Розпакуйте цей ZIP. На сторінці нового репозиторію натисніть
   **uploading an existing file** (або **Add file → Upload files**) і перетягніть
   **весь вміст розпакованої папки, зі збереженням підпапок**, зокрема `.github`.
   Підтвердьте кнопкою **Commit changes**. Якщо Chrome не дає перетягнути
   підпапки, використайте GitHub Desktop, але Python все одно не знадобиться.
4. Відкрийте вкладку **Actions**. Якщо GitHub запропонує дозволити workflows,
   підтвердьте. Знайдіть **«Build Windows EXE»**.
   За потреби натисніть **Run workflow → Run workflow**.
   Перший `push` також запускає збірку автоматично.
5. Дочекайтеся **зеленої позначки**. Відкрийте виконання,
   внизу сторінки знайдіть **Artifacts** і натисніть
   `Pomichnyk_Uchytelia_Windows_EXE`.
6. Завантажте ZIP, розпакуйте його. Всередині буде
   **Pomichnyk_Uchytelia.exe** — запускайте подвійним клацанням.

## Важливі застереження

- Google все одно попросить ваш дозвіл OAuth перед доступом до Classroom.
- Повні лекції можна готувати безкоштовно через власний ChatGPT (копіювання запиту й відповіді).
  Окремий OpenAI API-ключ потрібен лише для платного автоматичного режиму.
- Програма не публікує матеріали самостійно: тільки чернетки після вашого підтвердження.
- Уперше тестуйте розклад та підготовку Word без передачі документів у Classroom.
- Через відсутність цифрового підпису Windows SmartScreen може видати попередження.
- Не завантажуйте в репозиторій паролі, OAuth JSON, Google токени, AI ключі.

## Що зроблено під EXE

Раніше програма зберігала файли поряд із Python-кодом. Однофайловий EXE
розпаковується в тимчасовий каталог, тому це не працює.
Тепер налаштування і згенеровані Word зберігаються у вашій папці
`%LOCALAPPDATA%\PomichnykUchyteliaClassroom`,
що дозволяє зберігати прогрес між запусками.

Якщо в GitHub Actions виникне помилка, не потрібно вгадувати її причину:
достатньо показати текст червоного кроку.
