ПОМІЧНИК УЧИТЕЛЯ CLASSROOM — ОНОВЛЕННЯ 3.5
===========================================

1. КТП І РОЗКЛАД: ПЕРЕТЯГУВАННЯ
- Виправлено причину, через яку після перетягування КТП відкривалося вікно вибору файлу:
  імпорт ігнорував перетягнутий файл. Те саме було з розкладом.
- Редактор → «Календарні плани»: перетягніть DOCX/DOC/CSV на клас у списку зліва — клас
  підсвічується; якщо КТП у класу ще немає, програма створює його.
- Редактор → «Розклад»: перетягніть файл на таблицю (підсвічується) або «Завантажити
  навантаження / розклад». Програма читає ваш формат «8-Б ІУ / ГО», «/ 9-Г Право», «11 ІУ стандарт /».
- Назва «5-Г ІУ» у файлі автоматично зіставляється з єдиним потоком класу «5-Г історія».

2. СПИСОК КЛАСІВ ЗЛІВА — У ПОРЯДКУ CLASSROOM
- Після синхронізації порядок запам'ятовується; поки її не було — використовується останній
  збережений або порядок вашого налаштування. Клас без КТП — сірий «без КТП».

3. «НАВАНТАЖЕННЯ» У ВАШОМУ ФОРМАТІ
- Розклад → «Згенерувати Word «Навантаження»» і «… JPEG …»: A4, Times New Roman, рамки,
  заголовок «НАВАНТАЖЕННЯ (прізвище) // канікули … // код», червоний рядок харчування,
  час під номером уроку, «чисельник / знаменник». Прізвище й код вписуються в тому ж вікні.

4. ЗРАЗКИ ДОКУМЕНТІВ І ПРОМТИ (кнопка вгорі справа)
- Зразок розкладу та КТП (Word) + точні промти для ШІ; програма читає саме такі документи.

5. «МОЇ ДАНІ» (кнопка вгорі справа)
- Показує папку з усіма даними; «ZIP» зберігає копію всього без паролів, токенів і OAuth-файлів.

6. ВІКНА, КЛАВІШІ, РЕДАКТОР
- Усі діалоги — зручного розміру, по центру, без обрізання (перевірено 1920×1080 і 1366×768).
- Закриття редактора з правками: «Зберегти / Ні / Скасувати».
- «Класи / курси»: список відкривається ОДНИМ натисканням.
- Ctrl+C/V/X/A/Z/Y працюють в українській розкладці; Ctrl+S — зберегти; Esc — закрити діалог.
- Права кнопка на уроці: Word, ChatGPT, бібліотека, вкладення, редагування теми/Д/з в КТП,
  копіювання й збереження повідомлення, чернетки, перегляд Classroom, оновлення стану.
- «ПОЧАТКОВЕ НАЛАШТУВАННЯ» — лівіше від «ЧИСЕЛЬНИК/ЗНАМЕННИК»; «Підключити Google / одержати
  курси» — правіше. Кнопки «Копіювати повідомлення» і «Зберегти опис уроку» прибрано з панелі
  (лишились у правій кнопці).

7. СИНХРОНІЗАЦІЯ З CLASSROOM
- Через 1,5 с після запуску (якщо Google уже підключено): курси, їх порядок, усі чернетки й
  опубліковані матеріали/завдання. Кнопка вгорі робить те саме й за потреби просить дозвіл.
  Лише читання.

8. ЛЕКЦІЇ ЧЕРЕЗ ChatGPT
- «Відкрити ChatGPT» сама копіює запит. Адреса вашого ChatGPT запам'ятовується для всіх уроків.
- Запит просить Word за вашим зразком (Letter, TNR 14, кольорові блоки, колонтитули) та
  інфографіку PNG. У Word код уроку не пишеться.
- Файл: «Урок № 8, 02.10.2026 Тема.docx» (у папці «Готові Word/<дата>/<потік>/»).
- Перетягніть Word і PNG у вікно: Word стає лекцією уроку й паралелі (дата й Д/з — останнім
  рядком), PNG — вкладенням до чернетки. Запасний варіант — текстова відповідь, як у 3.4.
- «Лекції ГПТ на весь день»: один запит на всі уроки; файли перетягуються разом і розкладаються
  за назвою/темою; нерозпізнані призначаються вручну.

9. ОФОРМЛЕННЯ
- Єдина тема кольорів, шапка з градієнтом, таблиці, вкладки, виразні кнопки ChatGPT.

КОНТРОЛЬНИЙ СЦЕНАРІЙ НА WINDOWS

клас у списку зліва: клас має підсвітитися, а після відпускання відкритися «перегляд імпорту»
(а НЕ вікно вибору файлу) → «Прийняти» → «ЗБЕРЕГТИ ВСІ ЗМІНИ».

ВІДОМІ ОБМЕЖЕННЯ
- «Гола програма» ще не зроблена: ваш розклад і КТП поки вбудовані в EXE та лежать на GitHub.
  Копія всіх даних — кнопка «Мої дані».
- Google API не гарантує, що порядок курсів збігається з порядком на вашій сторінці Classroom.
  Якщо відрізнятиметься — повідомте.
- У навантаженні програма друкує назви ваших потоків («5-Г історія», а не «5-Г ІУ»).
  Восьмий урок (15.10–15.55) з'явиться, якщо додати його у «Навчальний рік».
- Чи створить ваш ChatGPT саме DOCX і PNG — залежить від вашого плану ChatGPT. Запасний шлях:
  текстова відповідь.
- Повідомлення для Classroom (шаблон) не змінювалось: у ньому ще є слова про відео та Word.
